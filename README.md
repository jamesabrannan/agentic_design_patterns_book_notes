## About the book

*Agentic Design Patterns: A Hands-On Guide to Building Intelligent Systems* by Antonio Gulli explores 21 patterns for building AI agents, including prompt chaining, routing, planning, memory, tool use, and multi-agent collaboration. It combines explanations with code examples to show how these patterns fit into practical agent workflows. This repository documents my study of those patterns in Java, and C#. ## Java examples and notes

The [LangChain4j Maven project](java/langchain4j/pom.xml) contains the initial Java implementation of the routing pattern. A model-backed coordinator classifies each request, and a conditional workflow selects a booking, information, or unclear-request handler. Each handler is declared as an annotated Java interface whose implementation is supplied by LangChain4j.

- [RoutingExample.java](java/langchain4j/src/main/java/com/jamesabrannan/agenticpatterns/langchain4j/routing/RoutingExample.java): console entry point with three sample requests.
- [Routing pattern notes](java/langchain4j/src/main/java/com/jamesabrannan/agenticpatterns/langchain4j/routing/routing-pattern.md): class descriptions, LangChain4j usage, flow and class diagrams, and current limitations, including the standalone-agent warning.

The project targets Java 17. Running the example requires `OPENAI_API_KEY` in the process environment and makes live model requests. Booking is acknowledged rather than performed; the example does not connect to a booking service or live search.

## n8n workflows

The n8n routing workflow classifies three sample requests, selects booking, information, or unclear-request instructions, and uses a shared LLM Chain to generate responses. Final nodes format each response, convert it to a text file, and save it to a Docker-mounted folder.

- [Pattern mapping and routing walkthrough](n8n/mapping-patterns-to-n8n.md): node configuration, workflow JSON, screenshot, flow diagram, and Docker output paths.
- [Importable routing workflow](n8n/workflows/routing-example-workflow.json): select your own OpenAI credentials after importing.
- [Docker Compose configuration](n8n/compose.yml): local n8n service and storage mounts.

Running the workflow makes live OpenAI requests. Booking is acknowledged rather than performed; the workflow does not make reservations or perform live searches. Additional workflows and notes will be added as the project progresses.
