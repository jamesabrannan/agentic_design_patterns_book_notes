# Agentic Design Patterns — Study Notes and Examples

This repository is a work in progress containing personal study notes and code examples for *Agentic Design Patterns: A Hands-On Guide to Building Intelligent Systems* by Antonio Gulli.

The collection currently includes **Python and Java** examples, with **C#** examples planned, exploring how the book's patterns can be implemented across languages and frameworks. Examples and explanations will be added and revised as I work through the book.

## About the book

*Agentic Design Patterns: A Hands-On Guide to Building Intelligent Systems* by Antonio Gulli explores 21 patterns for building AI agents, including prompt chaining, routing, planning, memory, tool use, and multi-agent collaboration. It combines explanations with code examples to show how these patterns fit into practical agent workflows. This repository documents my study of those patterns and adaptations in Python, Java, and C#. See the [publisher's description](https://link.springer.com/book/10.1007/978-3-032-01402-3).

## Java examples and notes

The [LangChain4j Maven project](java/langchain4j/pom.xml) contains the initial Java implementation of the routing pattern. A model-backed coordinator classifies each request, and a conditional workflow selects a booking, information, or unclear-request handler. Each handler is declared as an annotated Java interface whose implementation is supplied by LangChain4j.

- [RoutingExample.java](java/langchain4j/src/main/java/com/jamesabrannan/agenticpatterns/langchain4j/routing/RoutingExample.java): console entry point with three sample requests.
- [Routing pattern notes](java/langchain4j/src/main/java/com/jamesabrannan/agenticpatterns/langchain4j/routing/routing-pattern.md): class descriptions, LangChain4j usage, flow and class diagrams, and current limitations, including the standalone-agent warning.

The project targets Java 17. Running the example requires `OPENAI_API_KEY` in the process environment and makes live model requests. Booking is acknowledged rather than performed; the example does not connect to a booking service or live search.
